Blinkit Sales Performance Dashboard

This dashboard provides a comprehensive overview of Blinkit’s sales performance across outlets, products, and customer preferences. It highlights key KPIs such as $1.20M in total sales, $141 average sales, 8,523 items sold, and an average customer rating of 3.9, giving a quick snapshot of overall business health.

The dashboard analyzes sales trends over time through outlet establishment year, showing growth patterns and peak performance periods. It further breaks down performance by outlet size (Small, Medium, High) and location tiers (Tier 1, Tier 2, Tier 3) to identify high-performing regions and formats.

Product-level insights include sales contribution by item type and fat content, helping understand customer demand and category performance. Additionally, the outlet type comparison (Supermarkets and Grocery Stores) evaluates total sales, number of items, average sales, ratings, and item visibility.

Interactive filters for outlet location, outlet size, and item type enable focused analysis. Overall, this dashboard supports data-driven decisions by identifying sales drivers, outlet efficiency, and product performance across Blinkit’s operations.
